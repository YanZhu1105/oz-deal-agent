# Security

Please do not publish vulnerabilities, secrets or personal data in a public issue.

Use GitHub's [private vulnerability reporting](https://github.com/YanZhu1105/oz-deal-agent/security/advisories) and select “Report a vulnerability” to describe the issue, affected version, impact and reproduction steps. Do not include real credentials or a user's database; use a redacted example. The maintainer will review reports as capacity permits; there is currently no guaranteed response time.

The project is an early prototype. It runs inside an AI host with the permissions you give that host; posts and merchant pages are untrusted input. Review the host's permissions and keep the local database private.
