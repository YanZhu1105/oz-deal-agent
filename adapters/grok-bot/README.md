# Grok Bot adapter

See [setup and limitations](INSTRUCTIONS.md) and the [paste-ready prompt](PROMPT.md). This prompt-only integration has not been tested with a live Grok Bot; it is not a published Bot or a cloud service. In particular, reliable delivery history and feedback require the Bot to verify it has a durable private store across runs. The local Codex/Claude database cannot be accessed by a Grok Bot cloud routine merely by installing this repository.
